# Repository for "Iterative Foundation Model Fine-Tuning on Multiple Rewards"
This repository hosts the code implementation for the IterativeRS algorithm presented in the paper titled "Iterative Foundation Model Fine-Tuning on Multiple Rewards."

## Usage
To run the provided code and functionalities, please navigate to each folder and follow the corresponding instructions. The MPRA directory contains the implementation for the DNA sequence generation task, the QM9 directory includes the code for the small molecule generation task, and the summarize_from_feedback directory provides the implementation for the text summarization task.
